# Glossary for translators

Use these words for the terms of `CONTEXT.md` in every catalog of a locale, so
that one thing has one name in the whole interface. When the system has its
own word (a macOS setting, a key), use the word that the system shows in that
language.

## Voice and form

| | es | pt-BR | zh-CN | ja |
|---|---|---|---|---|
| Address the user | tú | você | 你 | No pronoun. です/ます form |
| Buttons and menu items | Infinitive: "Guardar" | Infinitive: "Salvar" | Verb: "保存" | Noun or verb + する: "保存" |
| Titles | Sentence case | Sentence case | No end mark | No end mark |
| Ellipsis | … | … | … | … |
| Quotes | «» or "" as in the English | "" | “” | 「」 |
| Space between Latin and CJK text | | | Space ("Sayso 已启动") | Space ("Sayso を起動") |

## Names that stay as they are

Sayso, Apple Intelligence, Claude Code, Codex, model names (Parakeet, Whisper),
provider names (OpenAI, Groq, ElevenLabs, Deepgram, AssemblyAI, Mistral), key
names (Option, Command, Ctrl, Shift, Esc, fn, Space), `config.toml` and other
file names, Hub.
